# Sales Intelligence architecture diagram

The SVG and PNG are generated from `draw_architecture.py` using the official
Google Cloud product icon set. The SVG is standalone: the product icons are
embedded as data URLs, so it does not depend on a CDN when viewed in GitHub,
slides, or a local file browser.

Regenerate the SVG after editing the layout:

```powershell
python docs/architecture/draw_architecture.py
```

The PNG preview is rendered at 1920x1080 from the generated SVG.

Icon source: [Google Cloud product icons](https://cloud.google.com/icons)
